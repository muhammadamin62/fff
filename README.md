# Асалим 🤍 — личный сайт-послание

## Как открыть

**Самый простой способ:** просто открой `index.html` в браузере (двойной клик). Всё работает без сервера.

**Через Flask (как просили):**
```bash
pip install flask
python app.py
```
Потом открыть в браузере: `http://127.0.0.1:5000`

## Как теперь работает сценарий

1. **Вход** — вводишь пароль. Если верно — сверху начинается настоящий **дождь из белых роз** (полсотни лепестков разом), и через секунду открывается...
2. **Видео на весь экран со звуком** (твоё `IMG_4367.MOV`, уже встроено как `media/intro.mp4`). Если браузер заблокирует автозвук — появится подсказка "тапни по экрану", и звук включится по нажатию. Есть кнопка "Пропустить" в углу.
3. После видео — **признание** (печатающийся текст).
4. После "Клик" — **слайд-шоу из 6 фото**, теперь медленнее (каждое фото держится ~2.6 секунды, плюс мягкое масштабирование).
5. **Финал** — сердце прорисовывается, фраза появляется и тихо тает.

Плюс добавил: золотую светящуюся "пыль" (искры), плавно летающую по всем экранам, и мягкое появление карточек (масштаб + fade) при каждом переходе.

## Фоновая музыка

Положи свой `music.mp3` в папку `media/` (или прямо в корень — путь легко поменять в `index.html`, ищи `bg-music`). Кнопка 🎵 справа снизу включает/выключает.

⚠️ Про "wishing you wodeshay" — не смог понять, что именно за трек ты имел в виду, и сам добавить готовую песню не могу: это будет чужая музыка под авторским правом, и у меня к тому же нет доступа в интернет, чтобы её скачать. Найди трек сам и просто положи файл `music.mp3` в папку `media/` (или в корень) — сайт его подхватит автоматически.

## Фото на экране слайд-шоу

Файлы `media/memory-1.jpg` ... `memory-6.jpg`. Меняешь — обновляется слайд-шоу.

⚠️ Два HEIC-файла с айфона так и не открылись (баг старой версии библиотеки на сервере). Если хочешь добавить именно их — экспортируй как JPEG ("Наиболее совместимый" формат при отправке) и пришли заново.

## Структура

- `index.html` — весь сайт (HTML + CSS + JS)
- `app.py` — необязательный Flask-сервер
- `media/intro.mp4` — твоё видео со звуком
- `media/memory-*.jpg` — фото для слайд-шоу
- `media/music.mp3` — добавь сам при желании
